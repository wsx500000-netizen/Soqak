# سوقك

سوقك تطبيق إعلانات وسوق عربي مبني بـ Flutter، بواجهة RTL وهوية موحدة على Android وiOS. يتيح استعراض الإعلانات، إنشاء إعلان للمراجعة، إنشاء الطلبات، وإدارة الإعلانات والمستخدمين والطلبات للمشرفين.

## تشغيل محلي

يتطلب Flutter. لتشغيل النسخة المحلية دون خادم:

```bash
flutter pub get
flutter run
```

تُحفظ بيانات النسخة المحلية في SQLite على الجهاز. إنشاء حساب المشرف المحلي للتجربة فقط، وليس وسيلة صلاحيات آمنة لتطبيق منشور.

## ربط Supabase

1. أنشئ مشروع Supabase.
2. نفّذ [supabase/schema.sql](./supabase/schema.sql) في SQL Editor للمشروع.
3. أضف عنوان المشروع ومفتاح **publishable/anon** إلى إعدادات التشغيل محلياً:

```bash
flutter run \
  --dart-define=SUPABASE_URL=https://YOUR_PROJECT.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
```

لا تضع `service_role` key أو كلمات المرور في التطبيق أو Git؛ مفتاح العميل وحده لا يمنح صلاحية المشرف، إذ تُفرض الصلاحيات بسياسات RLS ودور الحساب في قاعدة البيانات.

بعد إنشاء حسابك من التطبيق، امنحه دور الإدارة من SQL Editor، مع استبدال البريد بعنوان حسابك:

```sql
update public.profiles set role = 'admin' where email = 'owner@example.com';
```

لمنح صلاحية الإشراف بدلاً من الإدارة استخدم `supervisor`. يمكن للمشرفين والإداريين مراجعة الإعلانات وتغيير حالة المستخدمين والطلبات.

يدعم الربط السحابي حالياً المصادقة، الإعلانات وصورها، الطلبات، ولوحة إدارة الأدوار. تبقى المحادثات والمفضلة والسلة محلية؛ لا يوجد تحصيل إلكتروني أو مزامنة لهذه البيانات. الطلب المحفوظ ليس عملية دفع. أضف سياسة خصوصية نهائية وإعدادات البريد والدعم قبل إطلاق التطبيق.
